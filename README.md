# Retail Sales Analysis using Excel

Analysis of 1,000 retail transactions (2023) in Excel using
pivot tables, formulas and a dashboard.

## Tools Used
Excel: pivot tables, SUMIFS, COUNTIFS, INDEX/MATCH, charts

## What I Did
- Cleaned the data (0 blanks, 0 duplicates)
- Added helper columns: Month, Year, Age Group
- Built pivot tables: sales by month, category, age group and gender
- Created a dashboard with KPIs and charts

## Key Insights
- Total sales: 456,000 from 1,000 orders
- Best month: May (53,150)
- Top category: Electronics (156,905)
